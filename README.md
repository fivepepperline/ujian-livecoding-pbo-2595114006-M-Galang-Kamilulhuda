## Kasus 2 - Sistem tarif ekspedisi logistik 
Membuat program yang dapat menghitung hasil akhir seubah paket yang akan diantar oleh layanan ekspedisi,baik secara reguler maupun express, dengan  ketentuan:
1. Jika paket lebih dari 10 Kg,dikenakan biaya tambahan lebih sebesar Rp20.000
2. Jika nilai declared barang minimal Rp1.000.000 dikenakan biaya asuransi sebesar 1% dari nilai barang. jika dibawah itu, Biaya asuransi gratis

## Kasus 3 - Sistem Pemesanan Menu Kafe
Membuat program kasir pada sebuah kafe, dengan ketentua: 
1. Diskon 10% apabila jumlah pesanan diatas Rp60.000
2. Dikenakan biaya pajak resto sebesar 10% dari subtotal setelah dipotong diskon. 

# Petunjuk Menjalankan Program 
## Sistem tarif ekspedisi logistik 
1. Mengisi nomor resi, nama pengirim, layanan, berat paket, 
2. Sistem akan menghitung berdasarkan layanan, berat paket. Kemudian ditampilkan berupa tarif dasar, heavy surcharge, asuransi, dan total akhir ongkos. 

## Sistem Pemesanan Menu Kafe 
1. Mengisi nama customer, kemudian customer memilih menu yang tersedia, memilih kuantitas. 
2. Kasir menanyakan apakah ada pesanan lain?
3. Jika tidak, maka struk akan dicetak. Harga akhir merupakan hasil pengolahan dari pemilihan menu dan kuantitas dari customer, serta kebijakan toko yang memberikan diskon apabila subtotalmenyentuh angka Rp60.000 dan diatasnya, serta tambahan biaya pajak.
4. Jika iya, maka kasir menambahkan kembali menu dan kuantitas ke dalam sistem untuk diolah.
